# Telegram Gemini Bot films

Two independently composed, 20-second iPhone product films: landscape 1920x1080 and portrait 1080x1920, both 60 fps. The portrait has its own typography, phone position, scale, camera and API-line path. It is not a crop of the landscape film.

The phone and interface are staged film graphics using genuine retained bot responses, not a recording of native Telegram on an iPhone. The Bitcoin query, price/trend/risk excerpts and /brief quotes and summary come from the bot-engine recording on 14 October 2026, retained in demo-evidence.json. Quotes are historical. Processing time is shortened and is not a latency claim. No private chats, contacts, subscriber IDs, keys or credentials appear.

The visual uses a persistent iPhone surface, a light lavender/ivory/sage exterior, short relevant headlines and Telegram/Gemini logos. Its physically long request line illustrates an API request; it does not depict an observed network route.
